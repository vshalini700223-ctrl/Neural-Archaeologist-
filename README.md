# Neural Archaeologist AI

## Project Overview
Neural Archaeologist AI is an experimental AI-assisted web application designed to explore ancient inscriptions through digital image analysis, glyph segmentation, and script transliteration.

## Features
- Inscription image analysis
- Glyph segmentation and recognition
- Brahmi script transliteration
- Experimental historical reconstruction suggestions
- Exportable transcription and analysis reports

## Technology Stack
- **Frontend:** React, Vite, JavaScript
- **Backend:** Python, FastAPI

## Project Structure
- `backend/` — Backend application and API code
- `frontend/` — Frontend interface and assets

## Note
This is a learning prototype. OCR results and historical reconstruction suggestions are experimental and require verification by qualified epigraphy experts.

## Future Improvements
- Improve recognition accuracy using verified inscription datasets
- Add expert-validated translations
- Enhance the user interface and reporting features
